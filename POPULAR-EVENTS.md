# Top 5 popular events

The home page right sidebar ranks upcoming events by clicks + active saves + invitations, equally weighted. Each browser contributes at most one of each action per event. Unsaving removes its save contribution. Invitation links and referrals are deduplicated per event and inviter. Scores use recorded activity across all time; ended events are excluded. Fewer than five qualifying events are shown honestly without invented scores. RSVP status and organizer registration remain separate.
